# allirosedesign.github.io

Portfolio site for Alli Middleton (Alli Rose Design), published with GitHub Pages at https://allirosedesign.github.io.

- Pages: `index.html`, `portfolio.html`, `about.html`, `resume.html`, `journal.html`, `contact.html`
- Portfolio projects: one Markdown file each in `_projects/`
- Journal posts: `_posts/YYYY-MM-DD-title.md`
- Email, location and LinkedIn: `_config.yml`
- Styles: `assets/css/style.css`
